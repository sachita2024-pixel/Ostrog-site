# Ostrog-site
the landing page for "Ostrog"

## 🎯 About the Project

The website is built from scratch. The main goal is to demonstrate the company's reliability, service convenience, and provide residents with quick access to information about buildings, documents, and contacts.

## 🛠 Technologies

*   **HTML5** — semantic markup.
*   **CSS3** — **Flexbox**, `clamp()` for fluid typography, CSS variables, media queries, smooth animations, `@font-face`.
*   **JavaScript (ES6)** — interactive elements (modals, burger menu, slider).
*   **Swiper.js** — library for the object slider.
*   **BEM** — class naming convention for maintainable code.

## ✨ Features

*   **Responsive layout** (from 360px to 1620px).
*   **Burger menu** for mobile devices with smooth slide-down animation and scroll lock.
*   **Modals**:
    *   Emergency service (with phone number).
    *   Residential complex details (dynamic data injection via `data-` attributes).
    *   License viewing.
*   **Object slider** (Swiper) with adaptive settings and custom navigation buttons.
*   **Smooth scrolling** to sections on menu click (`scroll-behavior: smooth`).
*   **Cookie banner** (consent notice for data processing).
*   **Yandex.Metrica** — integrated for analytics tracking.
*   **Scroll-triggered animations** for sections (via `Intersection Observer`).


# Управляющая компания «Острог» 🏢

Одностраничный адаптивный сайт для управляющей компании, которая управляет многоквартирными домами в Иркутске.


## 🎯 О проекте

Сайт разработан с нуля. Главная цель — показать надежность компании, удобство сервиса и предоставить жильцам быстрый доступ к информации о домах, документах и контактах.

## 🛠 Технологии

*   **HTML5** — семантическая верстка.
*   **CSS3** — **Flexbox**, `clamp()` для резиновых шрифтов, CSS-переменные, медиазапросы, плавные анимации, `@font-face`.
*   **JavaScript (ES6)** — интерактивные элементы (модальные окна, бургер-меню, слайдер).
*   **Swiper.js** — библиотека для слайдера объектов.
*   **БЭМ** — именование классов для удобной поддержки кода.

## ✨ Что реализовано

*   **Адаптивная верстка** (от 360px до 1620px).
*   **Бургер-меню** для мобильных устройств с плавной анимацией выезда сверху и блокировкой скролла.
*   **Модальные окна**:
    *   Аварийная служба (с телефоном).
    *   Детали ЖК (с подстановкой данных через `data-` атрибуты).
    *   Просмотр лицензии.
*   **Слайдер объектов** (Swiper) с адаптивными настройками и кастомными кнопками навигации.
*   **Плавная прокрутка** к секциям по клику на пункты меню (`scroll-behavior: smooth`).
*   **Cookie-баннер** (плашка согласия на обработку данных).
*   **Яндекс.Метрика** — подключена для отслеживания аналитики.
*   **Анимация появления секций** при скролле (через `Intersection Observer`).
